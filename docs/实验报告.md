- 输入：fixtures/md-rd（main.c 包含 config.h；Makefile 声明 `main.o: main.c unused.h`）。
- 实际输出：程序输出 1；make-db.txt:1061 为声明行；trace/t.16:580 cc1 成功读 config.h；
  t.17:23 as 写 main.o；t.14:46 make 仅对 unused.h 做存在性检查、无进程读取。
