- `work/e5-01/evidence/trace/t.20:1` → `execve("/usr/bin/ld", [... "-o" "app" ... "main.o" ...]) = 0`。

- MD（漏声明，main.o）= `config.h`：实际被 cc1 读取，但 Makefile 未声明。
- RD（冗余声明，main.o）= `unused.h`：Makefile 声明了，但无任何编译/链接进程读取。
- `app` 仅读取 `main.o`，声明与实际一致，无 MD/RD。

     写打开记产物、O_RDONLY 记依赖、每作业恰一个最终输出否则显式 Unsupported。

     make-db.txt:1053 的 main.c 与 unused.h。

     如 t.14:579 pid14 读 config.h），声明−实际=REDUNDANT（证据=make-db 行号+声明原文，如 1053 行
     `main.o: main.c unused.h`）。
